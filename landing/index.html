Important Help

Windows shows a blue warning screen. What do I do?

This is Windows SmartScreen protecting your PC against newly released software. To continue, click "More info", then click "Run anyway". GitHub Installer is completely safe, transparent, and open-source.

Is GitHub Installer completely free?

Yes, 100% free and open-source under the MIT license. There are no subscriptions, hidden fees, or ads.

Do I need a GitHub account to install software?

No account is required. You can search, browse, download, and update software immediately right out of the box.

Where are apps installed?

Apps are neatly managed in your local user directory (%LOCALAPPDATA%\GitHubInstaller\Apps) with desktop shortcuts created for you, so it never alters protected system files.
